# Fees Management System

A full-stack Fees Management System built using the MERN stack.

## Features
- User Signup & Login
- JWT Authentication
- Secure Password Hashing
- Add & Delete Payments
- User-specific Dashboard
- Payment History
- Fee Summary (Total / Paid / Due)

## Tech Stack
### Frontend
- React.js
- Axios
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Authentication
- JWT
- bcrypt

## Project Structure
frontend/
backend/

## Installation

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start
